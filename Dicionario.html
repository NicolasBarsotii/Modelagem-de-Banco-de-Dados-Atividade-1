1. Entidade: FUNCIONARIO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
CD_FUNCIONARIOintegerIdentificador único do funcionárioChave Primária (PK)
NM_FUNCIONARIOvarchar(60)Nome completo do funcionárioNot Null (Obrigatório)
TP_CARGOvarchar(20)Cargo/função (atendimento ou cozinha)Domínio: {Atendimento, Cozinha}
NR_TELEFONEvarchar(15)Telefone de contatoOpcional
NM_EMAILvarchar(80)E-mail de contatoOpcional
IN_ATIVObooleanIndica se o funcionário está ativoDomínio: {true, false}

Notação formal

FUNCIONARIO = @CD_FUNCIONARIO + NM_FUNCIONARIO + TP_CARGO + (NR_TELEFONE) + (NM_EMAIL) + IN_ATIVO

2. Entidade: FORNECEDOR

Nome do Campo Tipo de Dado Descrição Restrição / Chave
CD_FORNECEDORintegerIdentificador único do fornecedorChave Primária (PK)
NM_FORNECEDORvarchar(80)Nome ou razão socialNot Null (Obrigatório)
NR_CNPJvarchar(18)CNPJ do fornecedorÚnico quando informado
NR_TELEFONEvarchar(15)Telefone de contatoNot Null (Obrigatório)
NM_EMAILvarchar(80)E-mail de contatoOpcional
DS_ENDERECOvarchar(120)Endereço do fornecedorOpcional
NM_CONTATOvarchar(60)Pessoa responsável na empresaOpcional
IN_ATIVObooleanIndica se o fornecedor está ativoDomínio: {true, false}

Notação formal

FORNECEDOR = @CD_FORNECEDOR + NM_FORNECEDOR + (NR_CNPJ) + NR_TELEFONE + (NM_EMAIL) + (DS_ENDERECO) + (NM_CONTATO) + IN_ATIVO

3. Entidade: PRODUTO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
CD_PRODUTOintegerIdentificador único do produtoChave Primária (PK)
NM_PRODUTOvarchar(60)Nome do produto (ex: X-Burger)Not Null (Obrigatório)
DS_PRODUTOvarchar(120)Descrição do produtoOpcional
TP_CATEGORIAvarchar(30)Categoria (Lanches, Refeições, Bebidas, etc.)Not Null (Obrigatório)
VL_VENDAnumeric(7,2)Preço de venda atualDomínio: >= 0
VL_COMBOnumeric(7,2)Preço quando vendido como comboOpcional, >= 0
TP_UNIDADEvarchar(10)Unidade de medida (un, porção, prato)Not Null (Obrigatório)
TP_ESTOQUEvarchar(10)Tipo de estoque (Interno ou Amostra)Domínio: {Interno, Amostra}
QT_ESTOQUEintegerQuantidade disponível em estoqueDomínio: >= 0
QT_ESTOQUE_MINintegerQuantidade mínima para alertaDomínio: >= 0
IN_PERECIVELbooleanIndica se o produto é perecívelDomínio: {true, false}
IN_PERMITE_ACOMPbooleanPermite escolher acompanhamentosDomínio: {true, false}
IN_PERMITE_COBbooleanPermite escolher coberturasDomínio: {true, false}
IN_ATIVObooleanIndica se o produto está ativoDomínio: {true, false}

Notação formal

PRODUTO = @CD_PRODUTO + NM_PRODUTO + (DS_PRODUTO) + TP_CATEGORIA + VL_VENDA + (VL_COMBO) + TP_UNIDADE + TP_ESTOQUE + QT_ESTOQUE + QT_ESTOQUE_MIN + IN_PERECIVEL + IN_PERMITE_ACOMP + IN_PERMITE_COB + IN_ATIVO

4. Entidade: ESTOQUE_MOVIMENTACAO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
CD_MOVIMENTACAOintegerIdentificador único da movimentaçãoChave Primária (PK)
CD_PRODUTOintegerProduto movimentadoChave Estrangeira (FK) → PRODUTO
CD_FORNECEDORintegerFornecedor da entrada (quando aplicável)Chave Estrangeira (FK) → FORNECEDOR (opcional)
TP_MOVIMENTACAOvarchar(10)Tipo (Entrada, Saída ou Ajuste)Domínio: {Entrada, Saída, Ajuste}
QT_MOVIMENTACAOintegerQuantidade movimentadaDomínio: > 0
DT_MOVIMENTACAOdateData da movimentaçãoNot Null (Obrigatório)
DS_OBSERVACAOvarchar(120)Observação sobre a movimentaçãoOpcional

Notação formal

ESTOQUE_MOVIMENTACAO = @CD_MOVIMENTACAO + CD_PRODUTO + (CD_FORNECEDOR) + TP_MOVIMENTACAO + QT_MOVIMENTACAO + DT_MOVIMENTACAO + (DS_OBSERVACAO)

5. Entidade: PEDIDO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
CD_PEDIDOintegerIdentificador único do pedidoChave Primária (PK)
CD_FUNCIONARIOintegerFuncionário que registrou o pedidoChave Estrangeira (FK) → FUNCIONARIO
DT_PEDIDOdateData do pedidoNot Null (Obrigatório)
TP_CANALvarchar(15)Canal do pedido (Balcão, WhatsApp, Telefone)Domínio: {Balcão, WhatsApp, Telefone}
TP_STATUSvarchar(15)Status do pedidoDomínio: {Aberto, Em preparo, Entregue, Cancelado}
NM_CLIENTEvarchar(60)Nome do cliente (quando informado)Opcional
NR_TELEFONE_CLIvarchar(15)Telefone do cliente (quando informado)Opcional
VL_TOTALnumeric(8,2)Valor total do pedidoCalculado, >= 0
VL_DESCONTOnumeric(7,2)Valor do desconto aplicadoDomínio: >= 0
DS_MOTIVO_DESCvarchar(60)Motivo do descontoEx.: funcionário da UNICID
DS_OBSERVACAOvarchar(120)Observações do pedidoOpcional

Notação formal

PEDIDO = @CD_PEDIDO + CD_FUNCIONARIO + DT_PEDIDO + TP_CANAL + TP_STATUS + (NM_CLIENTE) + (NR_TELEFONE_CLI) + VL_TOTAL + VL_DESCONTO + (DS_MOTIVO_DESC) + (DS_OBSERVACAO)

6. Entidade: ITEM_PEDIDO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
CD_ITEMintegerIdentificador único do itemChave Primária (PK)
CD_PEDIDOintegerPedido ao qual o item pertenceChave Estrangeira (FK) → PEDIDO
CD_PRODUTOintegerProduto do itemChave Estrangeira (FK) → PRODUTO
QT_ITEMintegerQuantidade pedidaDomínio: > 0
VL_UNITARIOnumeric(7,2)Preço unitário no momento da vendaDomínio: >= 0
VL_SUBTOTALnumeric(8,2)Quantidade × preço unitárioCalculado
DS_OBSERVACAOvarchar(120)Observação do itemOpcional

Notação formal

ITEM_PEDIDO = @CD_ITEM + CD_PEDIDO + CD_PRODUTO + QT_ITEM + VL_UNITARIO + VL_SUBTOTAL + (DS_OBSERVACAO)

Nome do Campo Tipo de Dado Descrição Restrição / Chave

CD_PEDIDOintegerPedido pagoChave Estrangeira (FK) → PEDIDO
TP_FORMA_PAGvarchar(15)Forma de pagamentoDomínio: {Débito, Crédito, Pix, Dinheiro}
VL_PAGAMENTOnumeric(8,2)Valor pagoDomínio: > 0

TP_STATUS_PAGvarchar(10)Status do pagamentoDomínio: {Pendente, Pago, Cancelado}

Notação formal

PAGAMENTO = @CD_PAGAMENTO + CD_PEDIDO + TP_FORMA_PAG + VL_PAGAMENTO + DT_PAGAMENTO + TP_STATUS_PAG

8. Entidade: PRATO_DO_DIA

Nome do Campo Tipo de Dado Descrição Restrição / Chave
CD_PRATO_DIAintegerIdentificador único do prato do diaChave Primária (PK)
CD_PRODUTOintegerProduto ofertado como prato do diaChave Estrangeira (FK) → PRODUTO

Nome do Campo Tipo de Dado Descrição Restrição / Chave

CD_PRODUTO_ITEMintegerProduto que compõe o combo (ex: Batata)Chave Estrangeira (FK) → PRODUTO

TP_ACOMPANHAMENTOvarchar(15)Tipo (Acompanhamento ou Cobertura)Domínio: {Acompanhamento, Cobertura}
